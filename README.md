# 📋 Titanic 데이터 정제 실습 (Data Cleaning)

모두의 연구소 교육 과정 중 Data Cleaning 파트에서 학습한 내용을 정리한 실습 기록입니다.

> 🛠️ 사용 환경: &nbsp;Python, Pandas, Jupyter Notebook
> 

<br>

## 학습 목적

- 데이터 분석 전 필수 단계인 데이터 정제 흐름을 이해하고 실습
- 실제 데이터셋을 기반으로 결측치, 이상치, 중복값 처리, 텍스트 및 날짜/시간 데이터 처리 방법 등을 습득
- Pandas 메서드에 익숙해지며 분석 전 데이터의 상태를 점검하고 정비하는 습관을 기르기 위함


<br>


## 분석 프로세스

| 단계 | 내용 | 주요 메소드 |
| --- | --- | --- |
| 1 | 데이터 로드 및 기본 구조 확인 | `read_csv()`, `info()`, `describe()` |
| 2 | 불필요한 컬럼 제거 | `drop('Name', axis=1)` |
| 3 | 결측치 처리 | `dropna()`, `fillna()` |
| 4 | 이상치 탐지 및 처리 | `apply(lambda x: 80 if x>80 else x)` |
| 5 | 중복 데이터 처리 | `duplicated()`, `drop_duplicates()` |
| 6 | 데이터 형태 변환 | `rename()`, `replace()`, `map()`, `apply()` |
| 7 | 텍스트 처리 | `pd.to_numeric()`, `pd.to_datetime()`, `.str`, `.dt` |

## 💡 인사이트 및 결론

- 결측치는 단순 제거보다 데이터 특성에 맞게 적절히 대체하는 방식이 더 효과적이다.

  → &nbsp;특히 `Age`는 평균보다 중앙값이 이상치에 덜 민감하여 처리 방법으로 더 적절하였다.
  
- 결측치가 많은 컬럼(예를 들어, 50%~70% 이상 등)은 전체 제거도 고려 대상이다.

- 문자열 처리 시에는 str 접근자를 사용해야 Pandas Series에 메서드를 적용할 수 있다.

- 이상치는 모델의 편향을 유발할 수 있다.

  → &nbsp;단순 제거보다 데이터셋 특성, 사용할 알고리즘, 예측 목적 등을 고려하여 처리하는 것이 필요하다.

- 정제 과정을 거친 데이터는 분석 정확도와 신뢰도 향상에 크게 기여한다.
